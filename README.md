# OrbitFlow

A personal hybrid AI product workspace built with Next.js, Tailwind CSS, and a polished product dashboard aesthetic.

## Features

- Personal login flow
- Unlimited-mode dashboard
- Two pillar architecture
- Graphify system map
- Pillar Agent explanation chat
- Product-focused SaaS UI

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000
